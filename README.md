# Laberinto 3D: Robo del Tesoro

Prototipo web 3D para teléfono y computadora.

## Novedades
- 5 niveles progresivos con laberintos cada vez más grandes.
- Cofres que dan monedas extra.
- Puerta secreta que recompensa con monedas.
- Llave obligatoria para escapar de cada nivel.
- Trampas de pinchos, placas y barro que penalizan tiempo/monedas.
- Joystick táctil, controles por deslizamiento y teclado.
- Mejor tiempo guardado localmente en el dispositivo.

## Ejecutar
Abre `index.html` desde un servidor web o publícalo con GitHub Pages. Three.js se carga desde un CDN, así que se requiere conexión a internet.

## Controles
- Teléfono: joystick virtual o deslizar sobre el escenario.
- Computadora: flechas o WASD.

## Pendiente
La clasificación mundial en línea y el empaquetado como aplicación Android todavía deben implementarse.
